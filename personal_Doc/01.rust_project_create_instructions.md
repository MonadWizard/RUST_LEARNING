
# Rust Project Setup Guide

This guide will take you through the steps to create a Rust project and run the code locally.

## 1. Install Rust

To install Rust, you can use the following command based on your operating system:

### MacOS/Linux:
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

### Windows:
Go to [Rust's Official Website](https://www.rust-lang.org/tools/install) and download the installer. Follow the instructions to complete the installation.

After installation, verify Rust by running:
```bash
rustc --version
```

## 2. Create a New Rust Project

Rust projects are typically managed using Cargo, which is both a build system and a package manager.

### 2.1 Check Cargo Installation
Cargo should already be installed with Rust. Check if Cargo is installed by running:
```bash
cargo --version
```

### 2.2 Create a New Project
Run the following command to create a new Rust project:
```bash
cargo new hello_rust
```

This will create a new folder called `hello_rust` with the required files.

### 2.3 Enter the Project Directory
Navigate into the project folder:
```bash
cd hello_rust
```

## 3. Project Structure

The newly created Rust project will have the following structure:
```plaintext
hello_rust/
├── Cargo.toml
└── src
    └── main.rs
```

- **Cargo.toml**: This file contains project metadata (name, version, dependencies).
- **src/main.rs**: The main file where your Rust code goes.

## 4. Run Your First Program

By default, `main.rs` will contain a simple "Hello, world!" program. You can check it by opening the file:
```rust
fn main() {
    println!("Hello, world!");
}
```

To run this program, use:
```bash
cargo run
```

### Expected Output:
```bash
   Compiling hello_rust v0.1.0 (file:///path/to/hello_rust)
    Finished dev [unoptimized + debuginfo] target(s) in 0.55s
     Running `target/debug/hello_rust`
Hello, world!
```

## 5. Compile the Code

To compile the code without running it:
```bash
cargo build
```

This will generate a binary in the `target/debug/` directory. You can manually run the binary:
```bash
./target/debug/hello_rust
```

### 5.1 Compile for Release
To compile with optimizations for release (production):
```bash
cargo build --release
```

The optimized binary will be found in `target/release/`.

## 6. Modify the Code

Open the `src/main.rs` file and change the message:
```rust
fn main() {
    println!("Rust শেখা মজার!");
}
```

Run the program again:
```bash
cargo run
```

### Output:
```bash
Rust শেখা মজার!
```

## 7. Adding Dependencies

If you want to add external dependencies, you can do so by modifying the `Cargo.toml` file.

For example, to add the `rand` library, add this line under `[dependencies]`:
```toml
[dependencies]
rand = "0.8"
```

Then, update your `src/main.rs` file to use the `rand` crate:
```rust
use rand::Rng;

fn main() {
    let random_number = rand::thread_rng().gen_range(1..101);
    println!("Random number: {}", random_number);
}
```

To run this updated code:
```bash
cargo run
```

## 8. Summary

By following these steps, you can set up a new Rust project, run code locally, and add dependencies. Rust's build and tooling system, Cargo, makes it easy to manage and run projects efficiently.
